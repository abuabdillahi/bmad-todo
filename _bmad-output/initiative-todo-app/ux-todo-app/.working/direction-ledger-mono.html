Ledger Mono

A utilitarian ledger: monospace type, square corners, a hard 2px frame and dense ruled rows that fit the most todos per screen, especially on desktop where row buttons tighten to 30px (phone keeps 44px). Black on white with one green action colour, and a highlighter-yellow focus ring that is impossible to miss. Completed rows get a grey band and a boxed DONE tag; failures print as a status line beneath the list, like output at the foot of a terminal (trade-off: on a long list it can sit below the fold).

Completed todos: Grey row band plus a boxed 'DONE' tag before the text, muted text (6.7:1 light / 7.3:1 dark) and the native tick. No strikethrough, so the text stays fully legible. Announcer: status line directly beneath the list. Hex values, contrast ratios, radius, spacing and type sizes are in the <style> comment at the top of this file. Frames marked “focus ring shown” render the keyboard focus style statically so you can judge it.
