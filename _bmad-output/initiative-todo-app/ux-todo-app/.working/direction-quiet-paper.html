Quiet Paper

A personal notebook rather than an app: warm paper, a serif voice, hairline rules between rows and almost no chrome, so the list reads like a page you write on. The add form is a single underlined line and row actions are quiet underlined text links; the only solid shape on screen is the Add button. Completed todos are struck through and softened, and failures appear as a margin note between the form and the list, right where your eye returns after acting.

Completed todos: Strikethrough (1.5px) plus muted text (still 5.6:1 light / 6.3:1 dark) and the native checkbox tick. Announcer: margin note between the add form and the list. Hex values, contrast ratios, radius, spacing and type sizes are in the <style> comment at the top of this file. Frames marked “focus ring shown” render the keyboard focus style statically so you can judge it.
