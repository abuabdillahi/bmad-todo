Soft Cards, v3

The chosen soft-cards direction, tightened. Active todos are the raised, filled cards with the strongest text; completed todos recede in both modes into hollow dashed outlines with muted text, a quiet grey check and outlined buttons, so nothing done is brighter than anything still to do. Fields grow with their text and always show an n/200 counter; cards grow too, and every vertical gap comes from one 4/8/12/16/24/32 scale.

What changed from v2 (spacing only): fixed the cause of the missing gaps (reset selectors like .app p / .app ul / .app button out-ranked the component classes and zeroed their margins, fonts and colours; resets now use zero-specificity :where()). Gaps on the 4/8/12/16/24/32 scale: heading→first block 16, announcer→form 16, form group→list/empty/loading 24, field→inline error 8, card→card 12, card padding 12×16, circle→text 12, text→actions 8, field/error→Save/Cancel 8. Add button top-aligned and the same height as the resting field. Focus ring offset 3px. Empty state in a quiet panel; loading skeletons use real card gap and padding. Heading is now “BMad Todos”. Palette, done treatment, counter, auto-grow, wording and announcer position unchanged.

Auto-grow uses CSS field-sizing: content; this static mock also sets each textarea's rows to its content so it reads correctly in every browser.
